🔑 Changer le mot de passe

La nouvelle version est committée directement dans login.html via l'API GitHub → live pour tout le monde en ~30 sec après le push (le temps que GitHub Pages redéploie).

Pour pouvoir push automatiquement les changements de mot de passe dans login.html, on a besoin d'un GitHub Personal Access Token (PAT) avec le scope repo ou public_repo.

  1. Va sur github.com/settings/tokens/new (lien pré-rempli)
  2. Choisis une expiration (90 jours OK)
  3. Vérifie que public_repo est coché
  4. Clique "Generate token"
  5. Copie le token (commence par ghp_) et colle-le ci-dessous
⚠️ Stockage local : le token est sauvegardé dans localStorage de ce navigateur. Ne l'utilise pas sur un ordi partagé. Tu peux le révoquer à tout moment sur GitHub.
