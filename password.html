🔑 Changer le mot de passe

Le nouveau pass est stocké dans localStorage de ton navigateur — il prend le pas sur le pass codé dans login.html. Spécifique à ce navigateur.

Important : ce changement vaut uniquement pour ce navigateur. Pour synchroniser sur d'autres appareils ou de manière permanente côté serveur, modifie la variable DEFAULT_HASH dans login.html (puis commit/push).
